# RECIPO - Recipe Application

**Technologies Used**: HTML, CSS, Bootstrap, Node.js, Express.js, MongoDB

## Overview

RECIPO is a full-stack recipe application that enables users to find, upload, and manage recipes. Users can create accounts, browse recipes by categories, and upload their own recipes. The application is built using Node.js and Express.js for the backend, MongoDB for data storage, and HTML, CSS, and Bootstrap for the frontend.

## Features

- **User Account Management**: Users can create accounts, log in, and manage their profiles.
- **Recipe Uploads**: Users can upload their own recipes, including ingredients, descriptions, and instructions.
- **Recipe Categories**: Recipes are organized into categories for easy browsing.
- **Responsive Design**: The app is fully responsive, built using Bootstrap to ensure a seamless experience on all devices.
- **RESTful APIs**: Developed using Node.js and Express.js to handle user and recipe data.
- **MongoDB Integration**: Efficient storage and retrieval of recipes and user data with MongoDB.
